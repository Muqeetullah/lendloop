## Build mandate

Keep the product friendly and practical. Use real data and honest empty, loading, and error states. Present actions only when they work.

## Character and direction

A light cream canvas, cocoa emphasis, a serif display face, and clear sans serif interface text. Soft cookie tones and fine borders create structure without heavy shadows. The interface stays light regardless of the device color preference.

## Composition patterns

Use a centered content width, a compact navigation bar, a generous title region, and clear sections for live content. Use the same hierarchy for future authenticated screens.

## Component and usage rules

Use the cocoa accent for primary actions and focus indicators. Use labels that remain visible. Pair status colors with text. Prefer quiet borders to elevation.

## Responsive and accessibility direction

Stack content on small screens. Keep focus visible and controls comfortable to use. Support keyboard navigation and reduced motion.

## Dashboard navigation

Keep the landing page public and read only. Use a separate signed in dashboard with a clear navigation item for each task. Show one bounded page at a time and keep page controls visible and keyboard accessible. On small screens, wrap navigation without requiring sideways scrolling.
